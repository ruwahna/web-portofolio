Sertifikat Belajar Dasar Pemrograman JavaScript

Sertifikat kelulusan atas penyelesaian kelas Belajar Dasar Pemrograman JavaScript di Dicoding Academy. Sertifikat ini membuktikan pemahaman fundamental JavaScript sebagai fondasi utama pengembangan web interaktif dan Back-end development (Node.js) dengan total 46 jam pembelajaran.

Materi kelas ini disusun berdasarkan standar kompetensi industri yang divalidasi oleh AWS, mencakup paradigma OOP, Functional Programming, hingga manipulasi asinkron.

Materi & Kompetensi Utama

  1. Sintaksis & Struktur Data: Memahami tipe data dasar, operator, penanganan error, serta struktur data kompleks seperti Map, Set, Array, dan Object.
  2. OOP & Functional Programming: Menguasai paradigma berorientasi objek (Class, Inheritance) serta pemrograman fungsional (pure functions, currying, array map/filter).
  3. Asynchronous Process: Mempelajari cara kerja asinkron di JavaScript menggunakan Callback, Promise, dan Async/Await untuk menangani network request.
  4. Code Quality & Modularization: Menulis kode yang modular menggunakan ES6 Modules serta menerapkan gaya penulisan kode yang aman dan teruji.
