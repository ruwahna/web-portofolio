Sertifikat Belajar Dasar Pemrograman Web

Sertifikat kelulusan atas penyelesaian kelas Belajar Dasar Pemrograman Web di Dicoding Academy. Kelas ini memberikan pondasi mendasar HTML dan CSS sebagai tiga pilar utama pembuatan website, dengan total 41 jam pembelajaran.

Kurikulum materi disusun dan diverifikasi bersama Google Developers Authorized Training Partner untuk memastikan kompatibilitas standar industri global.

Materi & Kompetensi Utama

  1. Struktur Dokumen & Semantic HTML: Menggunakan elemen HTML semantik untuk memudahkan mesin pencari (SEO) membaca struktur halaman web secara rapi.
  2. Styling CSS Modern: Menguasai CSS rules, selectors, box model, colors, shadows, positioning, dan float layouting.
  3. Layout Responsif & Flexbox: Menerapkan teknik Flexbox modern dikombinasikan dengan Media Query untuk memastikan kegunaan halaman optimal pada layar handphone/mobile.
  4. Tugas Akhir Mandiri: Membangun proyek mandiri berupa halaman website bertema profil atau informasi terstruktur menggunakan standar semantic HTML dan responsive design.
