Sertifikat Belajar Membuat Front-End Web untuk Pemula

Sertifikat kelulusan atas penyelesaian kelas Belajar Membuat Front-End Web untuk Pemula di Dicoding Academy. Kelas ini mengajarkan pengembangan website yang memiliki fungsionalitas dinamis, interaktif, serta fitur penyimpanan data lokal, dengan total 45 jam pembelajaran.

Materi kelas ini disusun berdasarkan kebutuhan industri modern untuk melatih kemampuan membuat aplikasi Front-end yang mampu berinteraksi langsung dengan tindakan pengguna.

Materi & Kompetensi Utama

  1. BOM & DOM Manipulation: Mempelajari dan mempraktikkan cara memanipulasi elemen HTML dan properti CSS secara dinamis lewat kode JavaScript.
  2. Event Handling: Menerapkan event listeners (seperti klik, form submit, input perubahan) untuk merespons tindakan pengguna secara real-time.
  3. Web Storage API: Memanfaatkan LocalStorage dan SessionStorage untuk menyimpan data pengguna secara permanen di browser web tanpa memerlukan database back-end.
  4. Proyek Aplikasi Rak Buku (Bookshelf App): Tugas akhir berupa pembuatan aplikasi web interaktif pengelolaan buku dengan fitur CRUD (Tambah, Baca, Pindah status, Hapus buku) yang terintegrasi dengan Web Storage.
